Gomagine is an image editing tool that runs directly
in your command line.

Syntax:
> gomagine -src="..." -dst="..." -opts="options..."

Options:
- "gs" -> Grayscale
- "br(n)" -> Changes the image's brightness by the factor n
- "con(n)" -> Changes the image's contrast by the factor n
- "r90" -> Rotates the image by 90 degrees
